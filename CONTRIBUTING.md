# Contributing

## Report a problem

Open an issue at https://github.com/canmils/catala-music-radar/issues with your OS, Python version, the exact command, the artist name involved, and what you expected.

## Send a change

1. Fork the repository and create a branch.
2. Make one focused change.
3. Run `python -m unittest discover -s tests -v`. All tests must pass.
4. Open a pull request that explains the change.

Never commit your `.env` file or Spotify credentials.
